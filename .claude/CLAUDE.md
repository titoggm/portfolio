# Portfolio Building

## Context

This project focuses on creating a portfolio to apply to Product Desingner roles.

## Tooling

- Frontend:
  - Next.js
  - React
  - TypeScript
  - Tailwind CSS
  - ShadCN UI
  - Bun
  - React Terminal Emulator UI (react-terminal-emulator-ui)
  - Framer Motion-style animations via Motion
- No Backend

## Colors

- The fontend should ONLY use black, white and neutral colors.

- Always use `bun ` over `npm` or `yarn`
- Alwys use `uv` over `pip` or `poetry`
